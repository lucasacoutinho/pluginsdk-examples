# Answer from the Schemaloom documentation

Find the Schemaloom version the project uses. Check `schemaloom.toml`, the lockfile or the CI configuration. Ask only if none of them states it.

Search the documentation with the `docs` MCP server's tools for that version. Read each tool's description before calling it.

Answer with the command or configuration the documentation shows, and link each page you used. When the documentation does not cover the question, say so. Do not fill the gap with options from other migration tools.

For upgrades, list the breaking changes between the project's version and the target version in order. Point out each one that affects the project's configuration or migrations.
